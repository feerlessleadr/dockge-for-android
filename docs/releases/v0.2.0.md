# Dockge for Android 0.2.0

Updating Dockge itself, and updating many stacks at once.

## What is new
- **Update Dockge safely.** For the Dockge stack, the update is no longer the plain stack update (which took Dockge offline with no backup and no rollback). It is a Dockge update card, with a confirm. Dockge backs up its data first, restarts into the new version, and restores the previous one automatically if the new version does not start healthy. The app reconnects by itself and shows each step until the result.
- **Update all.** Each server's stack list has an "Update all" button. It updates the stacks with updates one after another, shows each result, and never includes Dockge. A stack that fails does not stop the rest.

## Good to know
- Dockge's own update needs a backup set up on that Dockge server (Restic or Zerobyte). Without one, the update is refused before anything changes.
- Update all needs the app open. If the connection drops, the run stops and lists the stacks that were not updated.
- The Dockge update is new in this release and was checked by unit tests only, not yet on a live server. Back up Dockge's data before the first one.
- Requirements and other limits are unchanged from 0.1.1.

## Install
Obtainium updates from 0.1.1. By hand: download the APK below and compare its SHA-256 with the checksum file. Same signing key as 0.1.0 and 0.1.1.
